# El-Paso-Nightmare-VR
VR Mod for El Paso Nightmare

unzip to game folder, only tested with virtual desktop XR,

to disable Mod rename winhttp.dll to winhttp.dll.bak
  
  
  Always: A + B together = Start (menu), X + Y together = Back (view / map)
  Menus (the mod drives them): left stick / D-pad = move, left / right = change a setting, A = select, B = back
          (the menu laser + right trigger works as the mouse too)
  Mod:    HOLD the right stick click (about 1 second) = first / third person 3rd person not good,
          L3 + A / L3 + X = adjust the right / left weapon in your hand
          both stick clicks = re-centre, hold them = VR settings menu
